# Shop Parser — сбор каталога интернет-магазина в Excel

Консольный скрипт на Python, который обходит каталог интернет-магазина
(категории с пагинацией) и выгружает карточки товаров в Excel — типовая
задача для заказов на парсинг каталога на фриланс-биржах.

Для демонстрации используется [books.toscrape.com](http://books.toscrape.com/) —
учебный сайт-магазин книг, специально созданный для тренировки парсеров:
скрапинг там официально разрешён без ограничений, никаких юридических
вопросов не возникает. Логика и структура кода при этом ровно та же, что
используется для парсинга каталога реального интернет-магазина.

## Что делает скрипт

1. Заходит на главную страницу и получает список всех категорий каталога
   (либо одну категорию, если она указана в `--category`).
2. Для каждой категории обходит все страницы пагинации до последней.
3. С каждой карточки товара собирает: **название, цену, наличие,
   категорию, рейтинг (1–5), ссылку на карточку товара**.
4. Сохраняет результат в Excel с читаемыми заголовками столбцов и
   подобранной шириной колонок.
5. Выводит в консоль прогресс (какая страница обрабатывается) и итоговую
   статистику (сколько товаров собрано, сколько ошибок/пропусков).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Примеры запуска

```bash
# Весь каталог
python parser.py

# Одна категория
python parser.py --category "Travel" --output output/travel.xlsx

# Своя задержка между запросами (по умолчанию 0.75 сек)
python parser.py --category "Mystery" --delay 1.0
```

Параметры:
- `--category` — название категории (например, `Travel`). Без параметра
  обрабатываются все категории каталога.
- `--output` — путь к результату (по умолчанию `output/books.xlsx`).
- `--delay` — задержка между запросами в секундах (по умолчанию `0.75`).

## Устойчивость и этичность парсинга

Это отдельная зона ответственности при заказе на парсинг, поэтому вынесена
явным разделом, а не спрятана внутри кода:

- **Задержка между запросами** (`--delay`, по умолчанию 0.75 сек) —
  скрипт не долбит сервер запросами подряд, а выдерживает паузу перед
  каждым следующим обращением. Значение настраивается под требования
  конкретного сайта.
- **Корректный User-Agent** — запросы отправляются с заголовком,
  представляющимся как парсер, а не маскируются под обычный браузер
  исподтишка.
- **Ретраи при сетевой ошибке** — если страница не отдалась (обрыв
  соединения, таймаут, 5xx-ошибка), скрипт делает до 3 попыток с паузой
  между ними и только после этого помечает страницу как непрочитанную
  и переходит дальше, не прерывая весь запуск.
- **Обработка отсутствующих полей** — если на карточке товара нет
  ожидаемого поля (например, не распознан рейтинг), скрипт подставляет
  значение `"не указано"` и продолжает работу, а не падает с ошибкой.
- **Понятные сообщения об ошибках** — если сайт недоступен или не
  найдена запрошенная категория, в консоль выводится понятный текст
  (с перечислением доступных категорий), а не трейсбек Python.

## Как устроен код

Код разложен на отдельные функции, каждая отвечает за один шаг:

- `get_page()` — скачивает страницу (с ретраями и задержкой);
- `get_categories()` — достаёт список категорий с главной страницы;
- `get_next_page_url()` — находит ссылку на следующую страницу пагинации;
- `parse_product_card()` — извлекает данные одного товара из карточки;
- `scrape_category()` — обходит все страницы одной категории;
- `save_to_excel()` — сохраняет собранные данные в `.xlsx`.

Классы и сложные паттерны не используются — простой процедурный стиль.

## Ограничения

Это демонстрационный портфолио-проект под конкретный тип заказа
(каталог с категориями и пагинацией в духе books.toscrape.com), а не
универсальный фреймворк для парсинга произвольных сайтов. Под реальный
магазин селекторы (`article.product_pod`, `p.price_color` и т.д.) нужно
адаптировать под конкретную вёрстку.
